# لسان | LISAN Translator

مشروع أندرويد مستقل عن Joker، ومعرّف التطبيق `com.lisan.translator`.

## محتويات المشروع
- تطبيق Android مبني باستخدام Kotlin وGradle.
- خدمة لوحة مفاتيح عربية مع معاينة أولية للترجمة.
- محرك اكتشاف لغة وترجمة باستخدام ML Kit.
- خدمة إمكانية الوصول لالتقاط النصوص التي يسمح التطبيق الآخر للنظام بقراءتها.
- خدمة فقاعة عائمة وإعدادات الصلاحيات.
- سير عمل GitHub Actions في `.github/workflows/build-apk.yml` لبناء نسخة Debug.

## رفع المشروع إلى GitHub
ارفع **محتويات هذه الحزمة كلها** إلى جذر مستودع `Targmli`، بحيث يظهر `settings.gradle.kts` بجانب مجلد `app`، ويظهر مجلد `.github/workflows` في جذر المستودع. لا ترفع ملف ZIP وحده.

## بناء APK
من تبويب Actions شغّل سير العمل `Build LISAN APK`. إذا نجح البناء، نزّل artifact باسم `LISAN-debug-APK` وافتح ملف ZIP الناتج لاستخراج `app-debug.apk`.

## حالة المشروع وحدوده
هذه حزمة مصدر وليست APK جاهزًا. لم يُنفّذ بناء Gradle فعلي في بيئة إعداد الحزمة الحالية، لذا يجب اعتبار أول تشغيل على GitHub اختبار بناء حقيقيًا. وظائف لوحة المفاتيح والفقاعة وإمكانية الوصول ما زالت نموذجًا أوليًا وتحتاج اختبارًا عمليًا؛ لا يُضمن أن تتمكن خدمة إمكانية الوصول من قراءة نصوص جميع التطبيقات أو الألعاب. قد تحتاج نماذج الترجمة إلى تنزيل عبر الإنترنت.

## الصلاحيات
- `INTERNET`: للسماح باتصالات الشبكة.
- `SYSTEM_ALERT_WINDOW`: يتطلب موافقة المستخدم من إعدادات Android لعرض الفقاعة فوق التطبيقات.
- خدمة إمكانية الوصول والكيبورد تتطلب تفعيلًا يدويًا من إعدادات Android بعد التثبيت.

لا يوجد إذن تطبيق باسم Android SDK؛ الـ SDK أدوات بناء يتم إعدادها داخل سير العمل.
